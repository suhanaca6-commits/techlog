### Project Description

The Perfect Straw Position is a fun and deliberately unnecessary web-based experiment that tries to find the "best" position and angle for placing a straw inside a cup.

The website allows users to compare different straw positions and observe which position provides the most convenient drinking experience. Because apparently, even drinking water needs scientific research. 🥤😂

### The Problem (that doesn't exist)

Where exactly should a straw be placed inside a cup to drink water most easily?

Centre? Side? Tilted? Straight?

Humanity has survived without knowing the answer, but our project decided that this extremely important question deserves investigation.

### The Solution (that nobody asked for)

We created an interactive website that allows different straw positions and angles to be compared.

The project presents the results in a simple and entertaining way, helping us identify the supposedly "perfect" straw position.

In short:

**We took a completely normal activity and made it unnecessarily scientific.** 🤓🥤

# Installation

No special installation is required.

1. Download or clone the project files.
2. Open the project folder.
3. Make sure the HTML, CSS and JavaScript files are in the correct locations.

# Run

Open the `index.html` file in any modern web browser.

The website can then be used to explore and compare different straw positions.
